# 本地生图工作台（个人分享版）

简体中文 | [English](README.en.md)

Windows 桌面文生图 / 图生图工具。界面是 WinForms 窗口，生成交给本机 ComfyUI，图片只存本地，不上传任何服务器。

**不含模型权重**，需要按《模型清单.md》自行准备。

## 功能

- 文生图 / 图生图（结构参考、特征参考）/ 批量生成 / 任务队列
- 4 个模型配置：Qwen-Image 2.1（标准 / Turbo）、SD 3.5 Medium、Z-Image
- 组合预设（画风 / 人物 / 表情 / 种族 / 体型 / 服装 / 构图）、提示词库、角色库，均可自行扩展
- 本机 Agent HTTP 接口（`127.0.0.1:19876`），可被 AI 助手调用

## 快速开始

1. 安装 ComfyUI 便携版（NVIDIA 显卡版，版本 ≥ 0.42.0）
2. 右键 `一键安装.ps1` → **使用 PowerShell 运行**
3. 按《模型清单.md》把权重放进对应目录（只放 Qwen Turbo 三个文件也能先跑）
4. 双击桌面「本地生图工作台」

详细步骤、界面说明、常见问题见 **[使用说明.md](使用说明.md)**。

## 不含什么

- 模型权重（按各自许可自行获取）
- 成人向内容、角色预设库、外部提示词库
- ComfyUI 源码（通过 HTTP 调用本机安装的 ComfyUI）
