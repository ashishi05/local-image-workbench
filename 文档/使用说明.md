# 本地生图工作台 · 使用说明

一个跑在自己电脑上的文生图 / 图生图桌面工具：界面是 Windows 窗口，画图交给本机的 ComfyUI，图片只存本地，不上传任何服务器。

这个分享包里是**程序层**（窗口、调度、模型配置、给 AI 用的接口），**不含模型权重**。模型按《模型清单.md》放到指定目录即可。

- 适合：Windows 10/11 64 位 + NVIDIA 显卡
- 首次安装大约 20 分钟（不含下载模型）
- 全部装完约占 49 GB 硬盘（程序 8 GB + 模型 39 GB）

> ⚠️ **使用前必读**：本工具仅限 **18 岁以上** 成年人用于合法、正当用途。
> 严禁生成涉及未成年人的性化内容、未经同意的真人合成、侵权或违法内容。
> 生成内容及其传播后果由使用者承担（法律规定由其他主体承担的除外）；完整条款见 **第十章「免责声明与使用条款」**。

## 二、装之前确认

1. **显卡**：NVIDIA，显存 12 GB 起比较稳；8 GB 能跑 1024×1024 但容易爆显存，建议降到 768 或 512。Qwen 2.1 标准版最吃显存，Turbo 版和 SD3.5 轻一些。
2. **硬盘**：程序 + 一个模型的组合大约 20 GB 起，四个模型全放约 39 GB。
3. **ComfyUI 便携版**：去 ComfyUI 官方 release 下 `ComfyUI_windows_portable_nvidia` 包，解压到空间够的盘（路径尽量短，别放中文目录深层）。**版本要 0.42.0 或更新**，否则没有 Qwen-Image 2.1 节点。
4. 解压后先双击一次 `run_nvidia_gpu.bat`，确认引擎能打开 `http://127.0.0.1:8188`，再关掉。这一步是排除显卡驱动 / Python 环境问题。

## 三、三步装好

### 第 1 步：解压分享包

解压到一个你找得到的位置，例如 `D:\生图工作台-分享`。不要在压缩包里直接运行脚本。

### 第 2 步：运行一键安装

右键 `一键安装.ps1` → **使用 PowerShell 运行**。

如果提示"禁止运行脚本"，打开 PowerShell 执行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

安装脚本会依次做这些事：

1. 自动找 ComfyUI 便携版根目录（找不到会让你粘贴路径）
2. 把工作台复制到 `<ComfyUI根目录>\QwenImageApp`
3. 写入引擎启动脚本
4. 检查 Python 依赖（aiohttp / requests / pillow，缺了自动 pip 安装）
5. 逐个检查模型文件，列出缺哪些、还差多少 GB
6. 建桌面快捷方式「本地生图工作台」

可加的参数（一般不用）：

```powershell
# 手动指定 ComfyUI 根目录、跳过模型检查
.\一键安装.ps1 -ComfyUIRoot "E:\ComfyUI_windows_portable\ComfyUI_windows_portable" -SkipModelCheck

# 装完顺便跑界面自检
.\一键安装.ps1 -RunSelfTest
```

### 第 3 步：放模型

按 `模型清单.md` 第二节，把权重放进 `<ComfyUI根目录>\ComfyUI\models\` 下对应的子文件夹。

最省事是从旧电脑直接 robocopy（清单里有现成命令）。只想先试试的话，**只放 Qwen 2.1 Turbo 那三个文件**（约 13.5 GB）就能开工。

放完重新打开一次工作台，模型下拉框会列出 `models.json` 里登记的 4 个模型；没放权重的模型选中后会报错，换一个即可。

---

## 四、第一次启动

双击桌面「本地生图工作台」，窗口出现。

- 第一次点「开始生成」会自动拉起 ComfyUI 引擎，**等 30～90 秒**是正常的（模型要读进显存）。
- 状态栏会显示"正在启动生图引擎…"，之后开始走进度。
- 引擎日志：`<ComfyUI根目录>\QwenImageApp\engine.log`，启动失败先看这里。
- 引擎只在后台跑，不需要你手动开 ComfyUI 网页。

### 顶部

- **选择模型**：4 个模型切换。切换后步数、引导强度会按模型默认值调整。
- **重启工作台**：保存设置并重开窗口。卡住时用。

### 提示词页

- **提示词库 / 选择角色 / 组合预设**：这一排按钮在提示词输入框上方。前两个读的是可选素材库，本包内是空的，点了会提示"素材库缺失"，属正常。
- 主输入框写你要的画面。**空一行 = 分段**：每段各生成「数量」张，适合一次出一组不同构图。
- **组合预设**：点开勾选画风、人物、表情、场景、光线、角度、体型、服装、构图等；勾选立刻把对应英文片段插进输入框，取消勾选会移除那段（你手动改过的内容不会被误删）。每一类还可以设成"每张随机抽一个"。
- 尺寸、步数、引导强度（CFG）、种子、数量、输出目录都在「参数与保存」里。

### 图片生成参数怎么调

| 参数 | 建议 |
|---|---|
| 尺寸 | 1024×1024 起步。显存紧就 768×768 或 512×512；宽高必须是 32 的倍数 |
| 步数 | Qwen 标准版文生图 25、图生图 40；Turbo 固定 8 步（不能改）；SD3.5 28；Z-Image 30 |
| CFG | Qwen 用 1.0（Turbo 也是 1）；SD3.5 4.5；Z-Image 4.0；图生图默认 5 |
| 种子 | `-1` 每次随机；填固定数字可复现，批量时会逐张 +1 |
| 数量 | 文生图 1～100；图生图等于参考图张数 |

### 图生图 · 编辑

1. 把图片**拖进右侧预览区**（或点"选择参考图"，可多选 1～100 张），会自动切到编辑模式。
2. 写修改要求，比如"把屋顶改成蓝色，保留建筑和视角"。
3. 选参考方式：修改原图（结构参考）或参考元素（人物 / 动作 / 画风）。
4. 生成时保持原图比例，按"清晰度"缩放，不会裁成文生图尺寸。

### 图生图 · 特征参考

只借原图的某一部分：人物外观 / 动作姿态 / 画风色彩 / 综合参考。适合"用这个角色的感觉，画一个全新场景"。

### 关键词助手

需要本机装 **Ollama** 并有文字模型（默认找 `http://127.0.0.1:11434`）。能做的事：

- 把你的一句中文想法扩写成英文详细提示词
- 中英互译
- 写分镜、写图生图修改要求
- 「解析图片」：用 WD14 Tagger 反推图片标签（需要 ComfyUI 里装 `ComfyUI-WD14-Tagger` 节点）

没有 Ollama 不影响生图，只是这个页签用不了。

### 结果与图片浏览

- 右侧预览显示最新结果；点图打开大图窗口：滚轮缩放、拖动、左右方向键翻页、Delete 移到回收站。
- 「打开文件夹」直接跳到输出目录。
- 图片按「角色名_序号.png」或「序号.png」命名，**不覆盖已有文件**，序号接当前文件夹最大值往后排。

### 任务队列

「任务队列」里能看到排队 / 执行中 / 完成的任务，支持暂停、上移、下移、移除、清空待执行。队列只在本次窗口有效；关掉窗口不会杀掉已经提交的后台任务，图片照样会保存。

## 七、常见问题

**点了开始生成，一直停在"正在启动生图引擎"**

看 `engine.log` 末尾。常见原因：ComfyUI 版本太旧没有 Qwen 节点、显存不足、模型文件名不对、8189 端口被占。

**报错"参数或模型配置未通过检查"**

多半是模型文件缺失或名字不匹配。对照 `模型清单.md` 的目录和文件名逐字核对。

**生成一张要很久 / 爆显存**

降尺寸（1024→768→512）、换 Turbo 模型、关掉其他吃显存的程序。图生图的 1536 档很吃显存，12 GB 以下建议 1024。

**8189 端口被占**

说明已经有一个引擎实例在跑（可能是你之前手动开的）。任务管理器结束对应的 python 进程，或重启电脑后只让工作台拉引擎。

**桌面快捷方式点了没反应**

快捷方式依赖 `QwenImageApp\本地生图工作台.ps1`。确认文件还在；也可以直接双击 `QwenImageApp\启动工作台.bat`。

**提示"素材库缺失"**

正常。角色库 / 提示词库是可选内容，本包没带。需要的话按 `工作台文件\素材库_角色.json` 里的空结构自己填，或用 AI 接口导入。

**图片没保存到我想的目录**

输出目录必须是完整绝对路径（例如 `D:\生图`），在「参数与保存」里改。

## 八、给 AI 助手用

工作台自带本机 HTTP 接口（`http://127.0.0.1:19876`，需要令牌），AI 可以直接提交任务、拿图、拿 image_id 继续改图，不需要模拟鼠标点击。

把 `文档\给AI的交接文档.md` 交给它就行。人手动操作和 AI 提交共用同一个队列，界面上能看到 AI 的任务。

---

## 九、卸载与迁移

- **卸载**：删掉桌面快捷方式，再删 `<ComfyUI根目录>\QwenImageApp`。模型和 ComfyUI 本体不受影响。
- **换电脑**：整个 ComfyUI 根目录复制过去即可（程序、模型都在里面）；`QwenImageApp\settings.json` 里的输出路径记得改。

## 附录 A：自己扩展（模型 / 预设 / 提示词库 / 角色库）

工作台是“程序 + 数据”的结构：模型清单、组合预设、提示词库、角色库都是独立 JSON。想加自己的东西，改数据文件就行，不用改程序。

> 本包不包含成人向模型、预设或提示词库。自行扩展时请遵守当地法律与平台规则；涉及未成年人的性化、剥削或其他侵害内容一律不允许，正常的儿童题材插画（绘本、亲子、校园日常等）不在此列，但须符合法律与平台规则，且不得含性化或侵害性表达。下面的例子都用风景、服装设计、光影这类正常绘画题材。

### A.1 加一个模型（4 步）

**第 1 步：把权重放对目录**

| 权重类型 | 放到 |
|---|---|
| 单文件 checkpoint（SDXL / SD3.5 系） | `ComfyUI\models\checkpoints\` |
| 分离式 UNet / 主模型 | `ComfyUI\models\diffusion_models\` |
| 文本编码器 | `ComfyUI\models\text_encoders\` |
| VAE | `ComfyUI\models\vae\` |

**第 2 步：准备模板**

模板是 ComfyUI 的 API 格式（节点 ID → `class_type` + `inputs`），不是网页里导出的 workflow。别从零写，复制现成的改：

| 你的模型 | 复制这个模板 | 要改的地方 |
|---|---|---|
| SDXL 类 checkpoint | `sdxl_template.json` | `ckpt_name` 改成你的文件名；`filename_prefix` 换个前缀 |
| SD3.5 类 | `sd35_template.json` | `ckpt_name`，以及 `clip_l` / `t5xxl` 两个文件名 |
| Qwen-Image 类 | `api_template.json` | `unet_name` / `clip_name` / `vae_name` |
| Z-Image 类 | `zimage_template.json` | `unet_name` / `clip_name` / `vae_name` |

**第 3 步：登记到 `models.json`**

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一短名，提交任务时用它，如 `mysdxl` |
| `name` | 是 | 下拉框显示名 |
| `template` | 是 | 模板文件名 |
| `kind` | 否 | `sd35` / `sdxl` / `zimage`；不写按 Qwen 处理 |
| `checkpoint` | 看模板 | 单文件 checkpoint 的文件名 |
| `diffusion_model` | 看模板 | 分离式主模型的文件名 |
| `text_steps` / `edit_steps` | 建议 | 默认步数；只支持文生图就两个填一样 |
| `text_cfg` | 否 | 文生图默认 CFG |
| `prefix` | 否 | ComfyUI 内部临时文件名前缀 |
| `fixed_sigmas` | 否 | 固定时间表（如 Turbo 的 8 步）；填了就必须严格按这个步数跑 |

示例——加一个风景插画模型：

```json
{
  "id": "mysdxl",
  "name": "我的 SDXL 风景模型",
  "template": "sdxl_template.json",
  "kind": "sdxl",
  "checkpoint": "landscape_v1.safetensors",
  "text_steps": 28,
  "edit_steps": 28,
  "text_cfg": 6.0,
  "prefix": "MySDXL/App",
  "fixed_sigmas": null
}
```

**第 4 步：验证**

重启工作台 → 模型下拉出现新项 → 用 512×512、1 张试跑一张风景。失败先看 `engine.log` 和 `jobs\<任务ID>\worker.stderr.log`。

注意：`kind` 为 `sd35` / `sdxl` / `zimage` 的模型只支持文生图；要图生图，模板和节点必须本身支持参考图，不要硬套。

### A.2 加预设（组合预设）

**方式一：界面里改（推荐）**

「组合预设」→ 选一个分类 → 「管理预设」→ 新增 / 改名 / 删除。保存后写入 `preset_library_changes.json`。

**方式二：直接改 `preset_library_changes.json`**

```json
{
  "version": 2,
  "deleted": [],
  "custom": [
    { "Key": "style:custom_a1b2c3d4", "Name": "画风 · 淡彩水粉", "Text": "soft watercolor, pastel palette, light paper texture", "Random": false },
    { "Key": "clothes:custom_e5f6a7b8", "Name": "服装 · 长风衣", "Text": "long trench coat, belted waist, rolled sleeves", "Random": false }
  ],
  "overrides": [
    { "Key": "lighting:1", "Name": "光线镜头 · 窗边自然光", "Text": "soft window light, gentle shadows, warm tone", "Random": false }
  ]
}
```

- `deleted`：要隐藏的内置项 Key
- `custom`：自建项，Key 必须是 `分类:custom_十六进制`
- `overrides`：覆盖内置项，Key 必须已存在
- 分类前缀：`style` 画风、`character` 人物、`expression` 表情、`race` 种族、`body` 体型、`clothes` 服装、`composition` 构图、`count` 人数、`haircolor` 发色、`hairstyle` 发型、`eyecolor` 瞳色、`pose` 姿势、`scene` 场景、`lighting` 光线镜头

### A.3 加提示词库

`素材库_提示词.json`：

```json
{
  "version": 1,
  "updated": "2026-10-26",
  "source": "自建",
  "groups": {
    "光影": [
      { "id": "L001", "text": "soft window light, gentle shadows, warm tone" },
      { "id": "L002", "text": "backlit silhouette, rim light, dramatic contrast" }
    ],
    "服装": [
      { "id": "C001", "text": "long coat, leather boots, canvas satchel" }
    ],
    "构图": [
      { "id": "F001", "text": "wide shot, rule of thirds, deep depth of field" }
    ]
  }
}
```

- `groups` 的键就是界面里的分类名，值是 `{id, text}` 数组
- `text` 是真正拼进提示词的英文片段
- id 建议用「分类前缀 + 序号」，方便增删

### A.4 加角色库与收藏

`素材库_角色.json`：

```json
{
  "version": 1,
  "updated": "2026-10-26",
  "female": {
    "原创角色": [
      { "cn": "山间旅人", "en": "original character, mountain traveler", "desc": "green cloak, leather boots, canvas satchel" }
    ]
  },
  "male": {}
}
```

- 结构：`female` / `male` → 作品名 → 角色数组
- `cn` 界面显示名；`en` 英文标签（拼进提示词）；`desc` 可选补充描述
- 「选择角色」支持按作品 / 体型筛选、收藏星级；收藏写在 `素材库_收藏.json`，key 是英文标签

### A.5 去哪找参考素材

- **ComfyUI 官方文档和示例工作流**：看节点怎么连、参数怎么给
- **模型发布页**（HuggingFace、Civitai 等）：作者一般会写推荐步数、CFG、负面词，照抄最稳
- **提示词写法教程**：学「主体 + 构图 + 光线 + 画风 + 质量词」的结构，比抄一大串标签有用

注意：核对来源和许可，别整包搬运来路不明的提示词库或角色库；不要找、不要填违法违规内容。

### A.6 生效、备份与回滚

- 模型：点顶部「重启工作台」或重开窗口
- 预设：关掉「组合预设」再打开
- 提示词库 / 角色库：重新点按钮读取；Agent 侧约 6 秒后重新导出目录
- 改之前先备份：把原文件复制成 `.bak-日期`
- JSON 写坏时工作台只会报「读取失败」，不会覆盖原文件；把备份改回来即可

### A.7 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 新模型不出现 | `models.json` 语法错，或 `id` 重复 | 用 JSON 校验器验一遍 |
| 选中后报「模型配置未通过检查」 | 权重文件名和模板不一致 | 逐字核对 `ckpt_name` / `unet_name` |
| 加载报节点不存在 | 模板用了没装的节点 | 换模板或装对应节点 |
| 图生图按钮灰掉 | 模型 `kind` 不支持 edit | 换 Qwen 模型，或改模板支持参考图 |
| Turbo 报步数错误 | `fixed_sigmas` 要求固定 8 步 | 按 8 步提交 |
| 预设/提示词库不更新 | 没重新打开对话框 | 关掉重开；或重启工作台 |
