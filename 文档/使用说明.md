# 本地生图工作台 · 使用说明

Windows 桌面文生图 / 图生图工具。界面是窗口，生成交给本机 ComfyUI，图片只存本地，不上传服务器。

**不含模型权重**，需要按《模型清单.md》自行准备。

---

## 能做什么

- 文生图、图生图（改原图 / 借特征）、批量生成、任务队列
- 自带 4 个模型：Qwen-Image 2.1（标准 / Turbo）、SD 3.5 Medium、Z-Image
- 组合预设（画风、人物、表情、场景、光线、构图等）、提示词库、角色库，都能自己加
- 可选：本机 AI 助手接口，让 AI 直接提交任务

---

## 装之前

- Windows 10/11 64 位
- NVIDIA 显卡：12 GB 显存比较稳；8 GB 请把尺寸降到 768 或 512
- 硬盘：程序约 8 GB，模型约 39 GB（只放 Qwen Turbo 三个文件约 13 GB 就能先跑）
- ComfyUI 便携版（NVIDIA 版，**0.42.0 或更新**）

---

## 安装（三步）

**第 1 步：准备 ComfyUI**

解压 ComfyUI 便携版，先双击一次 `run_nvidia_gpu.bat`，确认能打开 `http://127.0.0.1:8188`，再关掉。

**第 2 步：运行安装器**

解压本包，右键 `一键安装.ps1` → **使用 PowerShell 运行**。

如果提示"禁止运行脚本"，先在 PowerShell 里执行一次：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

安装器会自动找 ComfyUI、复制程序、检查依赖、检查模型、创建桌面快捷方式。

**第 3 步：放模型**

按《模型清单.md》把权重放进 `ComfyUI\models\` 下对应子文件夹。只放 Qwen 2.1 Turbo 那三个文件也能先跑。

---

## 第一次生成

1. 双击桌面「本地生图工作台」
2. 右上角选模型（新手先用 `Qwen-Image 2.1 Turbo`）
3. 填提示词，选尺寸（1024×1024 起步），点「开始生成」
4. 第一次会自动启动引擎，**等 30～90 秒**是正常的

## 常用操作

**文生图**

- 提示词里**空一行 = 分段**，每段各生成「数量」张
- 想一次出多张：把数量调大，或写多段
- 种子 `-1` 每次随机；固定数字可复现，批量时逐张递增

**图生图 · 编辑**

- 把图片拖进右侧预览区，会自动切到编辑模式
- 写清楚"改什么、保留什么"，例如"屋顶改成蓝色，保留建筑和视角"
- 参考强度越高越接近原图

**图生图 · 特征参考**

- 只借原图的某一部分：人物外观 / 动作姿态 / 画风 / 综合
- 适合"用这个角色的感觉，画一个新场景"

**批量与队列**

- 文生图：数量 1～100，逐张生成
- 图生图：拖入多张参考图，每张各生成
- 任务队列支持暂停、上移、下移、移除；关窗口不会杀掉已提交的任务

**看图和删除**

- 点预览图打开大图：滚轮缩放、拖动、左右键翻页
- 大图里按 Delete 移到回收站

## 自己加东西

工作台的预设、提示词、角色、模型都是普通 JSON，**改文件 + 重启**即可，不需要改程序。

### 加分类 / 标签（最常用）

文件：`<安装目录>\QwenImageApp\预设库.json`

结构示例（加一个"季节"分类）：

```json
{
  "key": "season",
  "name": "季节",
  "items": [
    { "label": "春天", "text": "spring, cherry blossoms, fresh green" },
    { "label": "冬天", "text": "winter, snow, cold atmosphere" }
  ]
}
```

把它放进文件里的 `groups` 数组，保存后重启工作台，就会出现"季节"这一类。

规则：

- `key`：小写英文、不重复，决定分类 ID
- `name`：界面上显示的分类名
- `items`：每个标签一个 `label`（显示名）+ `text`（真正拼进提示词的英文）
- 想删分类：直接删掉对应那段
- 写坏了不生效：重启后会提示"预设库读取失败"，改回来即可

> 界面里「组合预设 → 管理」也能改，改动会另存到 `preset_library_changes.json`。想长期稳定，建议直接改 `预设库.json`。

### 加模型

1. 权重放进 `ComfyUI\models\` 对应目录（checkpoints / diffusion_models / text_encoders / vae）
2. 复制一份模板（`sdxl_template.json` / `sd35_template.json` / `api_template.json` / `zimage_template.json`），改成你的权重名
3. 在 `models.json` 里加一条（`id`、`name`、`template`、`kind`、`checkpoint` 或 `diffusion_model`、步数、CFG）
4. 重启，下拉框出现新模型，用 512×512 试一张

### 加提示词库

文件：`QwenImageApp\素材库_提示词.json`

```json
{
  "version": 1,
  "updated": "2026-10-26",
  "groups": {
    "光影": [ { "id": "L001", "text": "soft window light, warm tone" } ],
    "构图": [ { "id": "F001", "text": "wide shot, rule of thirds" } ]
  }
}
```

界面「提示词库」按分类浏览、搜索、勾选填入。

### 加角色库

文件：`QwenImageApp\素材库_角色.json`

```json
{
  "version": 1,
  "female": {
    "原创角色": [
      { "cn": "山间旅人", "en": "original character, mountain traveler", "desc": "green cloak, leather boots" }
    ]
  },
  "male": {}
}
```

界面「选择角色」可以按作品筛选、收藏、复制英文标签。

### 去哪找素材

- ComfyUI 官方文档和示例工作流：看节点和参数
- 模型发布页：作者通常给推荐步数、CFG、负面词
- 提示词写法教程：学"主体 + 构图 + 光线 + 画风 + 质量词"的结构

注意核对来源和许可，别整包搬运来路不明的库；不要用于违法违规内容。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 一直停在"正在启动生图引擎" | 看 `QwenImageApp\engine.log` 末尾；常见是 ComfyUI 版本旧、模型缺失、显存不足 |
| 报"模型配置未通过检查" | 权重文件名和模板里的名字不一致，逐字核对 |
| 生成很慢 / 爆显存 | 尺寸降到 768 或 512；换 Turbo 模型；关掉其他占显存的程序 |
| 图生图按钮灰着 | 只有 Qwen 模型支持图生图，先切到 Qwen |
| 提示"素材库缺失" | 正常，角色库/提示词库默认是空的，按上面格式自己填 |
| 快捷方式点了没反应 | 直接双击 `QwenImageApp\启动工作台.bat` |
| 8189 端口被占 | 之前手动开过引擎，任务管理器结束对应 python 进程再试 |
