# 模型清单与校验

工作台本身不含模型权重。这个文件说明：每个模型需要哪些文件、放到哪个目录、多大、以及怎么确认下载完整。

> 说明：这些权重是原工作台的作者自行准备的版本（含 int8 / w4a8 / fp4 量化版），来源与许可需自行核实。
> **优先从模型发布方获取**，并按其许可使用。自行迁移或向朋友提供副本前，请先确认该模型的再分发条件——有些许可禁止再分发、限制商用或要求署名；直接复制只适用于你已确认许可允许的场景。
> 重新下载时按文件名和大小核对，不要用同名但不同量化的版本替换。

## 四、怎么放

```
<ComfyUI根目录>
└─ ComfyUI\models\
   ├─ diffusion_models\  qwen_image_2.1_int8_convrot.safetensors ...
   ├─ checkpoints\       sd3.5_medium.safetensors ...
   ├─ text_encoders\     qwen3vl_8b_w4a8.safetensors ...
   └─ vae\               qwen_image_2.1_vae_bf16.safetensors ...
```

模型放在别的盘也可以：把 `运行时文件\extra_model_paths.yaml.example` 复制成 `ComfyUI\extra_model_paths.yaml`，改掉 `base_path` 指向你放模型的根目录。

## 五、校验

单个文件：

```powershell
Get-FileHash "<ComfyUI根目录>\ComfyUI\models\diffusion_models\qwen_image_2.1_int8_convrot.safetensors" -Algorithm SHA256
```

和上表的 SHA256 对比即可。文件大小对得上但哈希不对，说明是"同名不同版本"，工作台可能加载失败或画风不对。

## 六、许可允许时迁移（从原电脑复制）

先确认模型许可允许再分发或迁移，再在**旧电脑**上执行（管理员 PowerShell），把 `<旧根目录>`、`<新根目录>` 换掉：

```powershell
$src = '<旧根目录>\ComfyUI\models'
$dst = '<新根目录>\ComfyUI\models'
robocopy "$src\diffusion_models" "$dst\diffusion_models" qwen_image_2.1_int8_convrot.safetensors qwen_image_2.1_turbo_int8_convrot.safetensors z_image_int8_convrot.safetensors /J
robocopy "$src\checkpoints"      "$dst\checkpoints"      sd3.5_medium.safetensors /J
robocopy "$src\text_encoders"    "$dst\text_encoders"    qwen3vl_8b_w4a8.safetensors qwen_3_4b_fp4_mixed.safetensors t5xxl_fp8_e4m3fn.safetensors clip_l.safetensors /J
robocopy "$src\vae"              "$dst\vae"              qwen_image_2.1_vae_bf16.safetensors ae.safetensors /J
```

`/J` 让 robocopy 对超大文件做无缓冲复制，比资源管理器稳。网络传输的话用同一个命令，把 `$dst` 换成映射盘符即可。

| 文件 | 线索 |
|---|---|
| `sd3.5_medium.safetensors` | Stability AI 官方 `stable-diffusion-3.5-medium` 仓库根目录同名文件 |
| `t5xxl_fp8_e4m3fn.safetensors`、`clip_l.safetensors` | Comfy-Org 的 SD3.5 拆分权重包（`split_files/text_encoders/`） |
| `ae.safetensors` | Flux 的 VAE（Comfy-Org 拆分权重包 `split_files/vae/ae.safetensors`） |
| 四个 `*_int8_convrot` / `w4a8` / `fp4_mixed` | 作者自备的量化版，没有固定公开地址；按精确文件名检索，务必核对上表大小与 SHA256 |

> 量化版本不是随便换个 bf16 版就能替代：`models.json` 和模板里写死了文件名，工作台不会自动改。要换权重，得同时改 `models.json` / 模板，并在 ComfyUI 里验证节点能加载。
